# Работа с проектом

Локальный проект: «Библиотека», игра «Ночь в библиотеке».
Репозиторий GitHub: https://github.com/AntoninaLamert/library.
Удалённый репозиторий — `origin`, основная ветка — `main`.
Адрес для публикации игры: https://antoninalamert.github.io/library. GitHub Pages должен использовать ветку `main` и корневую папку `/`; сохраняйте относительные пути к файлам, чтобы игра работала в подпапке `/library/`.

По просьбе владельца завершённые изменения проекта необходимо самостоятельно проверять, фиксировать в Git и отправлять на GitHub без дополнительного подтверждения. Перед отправкой получайте актуальную удалённую историю и сохраняйте изменения, сделанные на GitHub. Не используйте принудительную отправку для перезаписи чужой истории.

При временной сетевой ошибке сохраняйте изменения локальным коммитом и повторяйте отправку при восстановлении доступа в ходе работы. Подтверждайте синхронизацию только после успешной отправки. Если отправить изменения не удалось, сообщайте об этом явно.

Для HTTPS используется Git Credential Manager и диспетчер учётных данных Windows. Не записывайте токены и другие секреты в файлы проекта, адрес remote, коммиты или сообщения.
